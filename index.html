📘 Week 1: Introduction to Artificial Intelligence & History ▼

1. Four Historical Perspectives of AI

AI definitions vary along two dimensions: Thought processes/reasoning vs. Behaviour and Human-like vs. Rational.

Perspective Focus Author & Definition in Slides
Thinking Humanly Cognitive Modeling Haugeland (1985): "The exciting new effort to make computers think... machines with minds, in the full and literal sense."
Acting Humanly Turing Test Approach Kurzweil (1990): "The art of creating machines that perform functions that require intelligence when performed by people."
Thinking Rationally Laws of Thought / Logic Winston (1992): "The study of the computations that make it possible to perceive, reason, and act."
Acting Rationally Rational Agent Approach Poole et al. (1998): "Computational Intelligence is the study of the design of intelligent agents."
⚠️ EXAM TRAP: Remember who said what! Haugeland = Thinking Humanly ("machines with minds"); Kurzweil = Acting Humanly ("functions that require intelligence"); Winston = Thinking Rationally ("computations that perceive, reason, act"); Poole = Acting Rationally ("design of intelligent agents").

2. Alan Turing & The Turing Test (1950)

  • The Imitation Game: A human interrogator communicates over a text-only channel with one human and one machine. The machine tries to fool the judge.
  • 1950 Prediction: By the year 2000, a machine might have a 30% chance of fooling a lay person for 5 minutes.
  • 4 Capabilities for Standard Turing Test:
    1. NLP: Communicate successfully in human language.
    2. Knowledge Representation: Store what it knows or hears.
    3. Automated Reasoning: Use stored information to answer questions and draw conclusions.
    4. Machine Learning: Adapt to new circumstances and detect patterns.
  • Total Turing Test adds physical interactions: Computer Vision (perceive objects) and Robotics (manipulate objects).

3. Key Historic AI Milestones in Slides

  • STANLEY (2005): Robotic driverless car finished 132-mile rough terrain Mojave desert course at 22 mph.
  • WAYMO: Google self-driving car project ("a new way forward in mobility").
  • Speech Recognition: United Airlines automated flight booking dialog system.
  • NASA Remote Agent: First on-board autonomous planning program controlling spacecraft scheduling.
  • PackBot: Robotic system for hazardous materials, explosive clearance, and locating snipers.
  • Spam Detection: Classifies over 1 billion messages daily; saves 80% to 90% of user inboxes from spam.
📗 Week 2: Intelligence, Generative vs. Agentic AI & Machine Learning ▼

1. Historical Origin of the Name "AI"

The term "Artificial Intelligence" was officially coined at the historic 1956 Dartmouth College workshop organized by John McCarthy, Marvin Minsky, Nathaniel Rochester, and Claude Shannon.

2. Generative AI vs. Agentic AI (Direct Slide Comparison)

Aspect Generative AI Agentic AI
Core Definition Creates new content (text, images, audio, video) based on prompts. Autonomous, goal-driven AI that plans, takes multi-step actions, and uses tools.
Operation Style Reactive, single-turn prompt response. Proactive, loop-based, iteratively assesses environment and corrects mistakes.
Slide Real-Life Scenario (Teaching) Creates lecture slides or writes essays. Designs course + delivers teaching + evaluates student progress.

3. Weak AI vs. Strong AI

  • Weak AI (Narrow AI): The assertion that machines could act as if they were intelligent. Examples: ChatGPT, Siri, Alexa, Recommender Systems, Self-driving cars.
  • Strong AI (AGI): Machines that actually think and possess genuine human-level minds/consciousness.

4. Machine Learning Fundamentals

  • Supervised Learning: Trained on labeled datasets (every training sample has a known ground truth output).
  • Unsupervised Learning: Trained on unlabeled data to discover hidden patterns or clusters.
  • Artificial Neural Networks (ANN): Input layer → Hidden layers → Output layer. Forward propagation makes predictions; backpropagation updates weights to minimize loss.
  • Convolutional Neural Networks (CNN): Specialized deep learning architectures designed for grid-like data (images, object detection).
📙 Week 3: Intelligent Agents & The 4 Agent Architectures ▼

1. Agent Definition & Fundamental Formula

  • An Agent is anything that perceives its environment through sensors and acts upon it through actuators.
  • Agent Function: Abstract mathematical mapping from percept histories to actions: f: P* → A.
  • Agent Program: Concrete implementation running on an architecture: Agent = Architecture + Program.

2. The 4 Agent Architectures (MUST MASTER FOR EXAM!)

Agent Type How It Works Key Features & Examples Major Limitations
1. Simple Reflex Agent Condition-Action rules (IF condition THEN action). Responds ONLY to current percept. No memory/history. Example: IVR system, basic thermostat. Fails in partially observable worlds; infinite loops; zero adaptability.
2. Model-based Reflex Agent Maintains an internal state to track unobservable world. 4-stage cycle: Sense → Model → Reason → Act. Knows how world evolves and how actions affect world. Example: Amazon Bedrock. Computationally costly to maintain models; real world is hard to model accurately.
3. Goal-based Agent Combines state with explicit Goal descriptions. 5 steps: Perception → Reasoning → Action → Evaluation → Goal Completion. Uses search and planning algorithms. Cannot differentiate between two equally valid paths to the same goal (no preference metric).
4. Utility-based Agent Evaluates states using a Utility Function (happiness/desirability score). Chooses action with highest expected utility. Manages trade-offs (e.g. speed vs safety, cost vs reliability). Complex utility functions; computationally demanding.
⚠️ EXAM QUESTION ALERT: If asked which agent chooses actions based on "trade-offs between conflicting goals or degree of desirability", the answer is ALWAYS Utility-based Agent!
📕 Week 5: The 6 Environment Classifications ▼

Russell & Norvig and your slides identify 6 distinct dimensions of task environments:

Dimension Type 1 Type 2 Exam Slide Examples
Observability Fully Observable: Complete state visible at any time through sensors. Partially Observable: Incomplete, noisy, or hidden data. Chess is Fully Observable. Taxi driving & Vacuum with only local sensor are Partially Observable.
Determinism Deterministic: Next state is 100% determined by current state and action. Stochastic: Randomness or unpredictable factors present. Vacuum world & Chess are Deterministic. Taxi driving is Stochastic (traffic is unpredictable).
Episodic vs Sequential Episodic: Atomic independent episodes; current action does NOT affect future episodes. Sequential: Current decision affects all future states and actions. Mail sorting & Image classification are Episodic. Chess and Taxi driving are Sequential.
Dynamics Static: World does NOT change while agent is deliberating. Dynamic: World continuously changes while agent is thinking. Crossword puzzles are Static. Taxi driving & football are Dynamic. (Chess with clock = Semi-dynamic).
Continuity Discrete: Finite, distinctly separate states, actions, and time steps. Continuous: Smoothly flowing spectrum of states and actions. Chess & 8-puzzle are Discrete. Taxi driving & drone navigation are Continuous.
Agent Count Single-Agent: Agent acts entirely alone. Multi-Agent: Multiple agents interact (competitive or cooperative). Crossword is Single-Agent. Chess is Multi-Agent (two competitive agents).

2. Graph Theory: In-Degree & Out-Degree Calculation (Direct Slide Problem)

Definition: In a directed graph:

  • Out-degree(x) = Number of directed edges leaving vertex x.
  • In-degree(x) = Number of directed edges entering vertex x.
📐 Exact Slide Example (Slide 18-22):
Given vertices: V = {u, v, w} and directed edges: E = {(u, w), (u, v), (v, w)}
• For u: Edges starting from u are (u,w), (u,v) → Out = 2. Edges ending at u: none → In = 0.
• For v: Edges starting from v: (v,w) → Out = 1. Edges ending at v: (u,v) → In = 1.
• For w: Edges starting from w: none → Out = 0. Edges ending at w: (u,w), (v,w) → In = 2.

3. Trees Properties

  • A tree is a connected, acyclic graph.
  • For any tree with N vertices, there are exactly N - 1 edges!

4. Five Components of a Well-Defined Search Problem

  1. Initial State: Starting configuration.
  2. Actions: Possible moves available.
  3. Transition Model: Description of what each action does.
  4. Goal Test: Checks if current state satisfies the objective.
  5. Path Cost: Sum of step costs along the path.

5. Uninformed Search: BFS vs. DFS Comparison

Criterion Breadth-First Search (BFS) Depth-First Search (DFS)
Data Structure FIFO Queue (shallowest node first) LIFO Stack (deepest node first)
Completeness Yes (if branching factor b is finite) No (fails in infinite paths or loops)
Optimality Yes (if all step costs are equal) No (can return deeper sub-optimal solution)
Time Complexity O(b^d) O(b^m) (m = maximum depth)
Space Complexity O(b^d) (EXPONENTIAL - Huge Memory Bottleneck!) O(bm) (LINEAR - Modest space is its strength!)
📓 Week 7: Knowledge Representation and Reasoning (KRR) ▼

1. What is Knowledge Representation (KR)?

KR is a branch of AI focusing on how machines store and use knowledge about the real world to reason, learn, and solve problems smartly. It enables systems to combine prior experience with input data to display intelligent behavior.

2. The 5 Types of Knowledge

Type Core Meaning Slide Example
1. Declarative Facts and concepts; answers "WHAT" something is. "Paris is the capital of France."
2. Procedural HOW to perform a task or execute a procedure. Steps to sort numbers using an algorithm.
3. Meta-Knowledge Knowledge about other knowledge; how to select rules. Knowing that a certain rule works better for solving calculus problems.
4. Heuristic Experience-based rules of thumb used by experts. A doctor using 20 years of clinical experience to guess a possible illness.
5. Structural Relationships, taxonomies, and hierarchies between concepts. "A car is a type of vehicle."

3. Four Knowledge Representation Techniques

  • 1. Logical Representation: Uses formal logic with precise Syntax (rules for constructing sentences) and Semantics (meaning and truth value).
  • 2. Semantic Networks: Graph representation with Nodes (objects/concepts) and directed Arcs (relations). Key relations: IS-A (inheritance, e.g. Cat IS-A Mammal) and Kind-of.
  • 3. Frame Representation: Structured data format with Slots (attributes) and Values. Resembles classes and objects in OOP; widely used in NLP and Computer Vision (e.g. Frame for Book with slots Title, Author, Year, Pages).
  • 4. Production Rules: IF condition THEN action. Consists of 3 components:
    1. Set of rules: Condition-action specifications.
    2. Working memory: Current state of problem facts.
    3. Recognize-Act cycle: Checking conditions against memory and firing the chosen rule.

📐 Slide Graph Degree Solver (Week 6, Slides 18-22)

Given Directed Graph with Vertices V = {u, v, w} and Edges E = {(u, w), (u, v), (v, w)}:

Vertex u:

Outgoing edges: (u,w), (u,v)

Incoming edges: None

Out-degree = 2 | In-degree = 0
Vertex v:

Outgoing edges: (v,w)

Incoming edges: (u,v)

Out-degree = 1 | In-degree = 1
Vertex w:

Outgoing edges: None

Incoming edges: (u,w), (v,w)

Out-degree = 0 | In-degree = 2
Key Rule: Total Sum of In-Degrees = Total Sum of Out-Degrees = Total Number of Edges (|E| = 3)!
